# Employee Management System

A full-stack web application to manage employee data efficiently. It allows users to add, edit, delete, view, search, sort, and paginate employee records.

## 🌐 Tech Stack

- **Backend**: Spring Boot (Java)
- **Frontend**: HTML, CSS (Bootstrap), JavaScript
- **Testing**: Postman
- **Database**: H2 (In-memory) or any other JDBC-compatible database

---

## ✨ Features

- ➕ Add New Employee
- ✏️ Edit Employee Details
- 🗑️ Delete Employee
- 📋 View All Employees
- 🔍 Search by Name, Email, Department, or Role
- 📑 Pagination (5 records per page)
- ↕️ Column Sorting (Name, Email, etc.)
- ✅ Form Validations
- 🧪 Postman API Testing
